# Конвейер анализа видео

Обновлено: 2026-08-14. Код и артефакты — в `analysis/` (окружение: `analysis/.venv`,
Python + OpenCV). Статус: идёт пилот (см. «Пилот» ниже).

Цель: алгоритмически сократить десятки часов съёмки до посильного для отсмотра
набора кропов-кандидатов с геопривязкой, ничего не потеряв. Приоритетное
направление — линия падения ниже точки рюкзака (4663 м): участок ниже 4529 м
не осматривался (`docs/nakhodki/README.md`).

## Слои конвейера

Каждый слой сокращает объём для следующего. Полный кадр 1080p для визуальной
модели бесполезен (объект — единицы пикселей), поэтому машинная математика
ищет «не снег и не камень», а визуальный разбор работает только по кропам.

1. **Геоиндекс.** Для каждой секунды каждого видео — позиция дрона, углы камеры,
   зум (из SRT или из встроенного потока DJI: GPS — `scripts/dji_meta_gps.py`,
   углы — там же в protobuf, поля gb_yaw/gb_pitch/gb_roll подтверждены
   волонтёрской выгрузкой `data/telegram/general/1141.zip`). Проекция взгляда
   камеры на рельеф (модель высот Copernicus GLO-30) даёт: карту покрытия
   (что осмотрено/не осмотрено), выборку «все кадры, где видна точка X»,
   координаты для любого кандидата. Фокусное расстояние метаданные не дают
   напрямую - берётся самокалибровкой по видео, см.
   `docs/focal-length-calibration.md`.
2. **Отбор кадров.** 1–3 кадра/сек, отбрасывание смазанных и статичных
   (дрон висит — видно по телеметрии). Приоритетные участки — покадрово.
3. **CV-предфильтр.** Кадр режется на плитки; в каждой ищутся цветовые аномалии
   (пиксели вне цветовой модели «снег+камень» текущей сцены), прямые линии
   (верёвки), блики. Калибровка порогов: подтверждённые находки обязаны
   проходить, «отклонённые» из TG — материал для оценки шума. Выход — кропы
   с файлом/таймкодом/гео.
4. **VLM-триаж.** Кропы монтируются в сетки с подписями, отсматриваются агентом
   (сабагентами), ранжирование по шкале штаба 1–5.
5. **Склейка и сравнение.** Кадры одного места из разных пролётов совмещаются
   по общим точкам (feature matching + гомография): склейка крупных планов
   в общий вид, разница между пролётами (шевеление ткани, изменения).
6. **Траектория падения.** Линия наибыстрейшего спуска от рюкзака по модели
   высот + коридор; пересечение с картой покрытия → список «видео+таймкод»,
   где коридор виден, и дыры для доснятия штабом.

Формат кандидата (по инструкции штаба): файл, таймкод, координаты, скриншот,
описание, уверенность 1–5, нужен ли повторный облёт. Сомнительное фиксируется
всегда, отсев — при сведении.

## Пилот: валидация на известных находках

Подход подтверждаем на том, что уже найдено (эталоны — `docs/nakhodki/README.md`):

| Эталон | Видео | Таймкод |
|---|---|---|
| Белый стакан с красной маркировкой | `DJI_20260813183004_0001_Z.MP4` | 3:40 |
| Бирюзовая крышка + синий фрагмент | `DJI_20260813183727_0015_Z.MP4` | 3:32 |
| Палка/крышка (зависание, 28 м) | `DJI_20260813183534_0014_Z.MP4` | 0:31 |
| Синий рюкзак | `helicopter/C0049.MP4` | 0:15–0:21 |
| Палки, крышка крупным планом | JPG `…183028_0002`, `…183101_0008`, `…183140_0012` | — |

Критерии успеха:

- Детектор помечает все эталонные объекты на кадрах, где их видит человек
  (пропуск эталона = провал, порог ослабляется).
- Объём кропов с полного видео посилен для VLM-отсмотра
  (ориентир: сокращение ≥50× против сплошного покадрового просмотра).
- VLM-отсмотр кропов отличает эталоны от шума (камни, наледь, лишайники).

### Результаты пилота (2026-08-14)

**Все критерии выполнены.** Recall на эталонах 100%: на покадровой проверке
стакан — ранг 7 из 107 блобов кадра, крышка и рюкзак — ранг 0 своих кадров,
палка размечена на обоих крупных планах (включая надпись KOMPERDELL).
На полных прогонах (1 кадр/с, топ-25 блобов на кадр, трекинг повторов):

- `DJI_20260813183004_0001_Z.MP4` (4,2 мин, 7500 кадров → 2206 треков):
  в топ-72 треках (2 монтажа) — палка, крышка, стакан (t65), оранжевый
  предмет; шум — легко отличимые камни.
- `DJI_20260813183727_0015_Z.MP4` (4,5 мин → 2317 треков): топ-6 треков —
  оранжевый предмет крупным планом, крышка — ранг 8.

Попутная находка: **атрибутирован «оранжевый предмет»** (в реестре находок
числился без исходника): `DJI_20260813183727_0015_Z.MP4` 3:26–4:00 крупно
(похож на ткань/чехол с белыми лентами) и `DJI_20260813183004_0001_Z.MP4`
0:02, 2:07–2:24; GPS дрона у объекта 39.48335 N 73.58502 E, ~4551 м.

Ограничение: пилот шёл по съёмке с близкого расстояния; на дальних планах
(объект в единицы пикселей) recall не подтверждён — проверять на облётах 12.08
с известными верёвками.

Конвейер экстраполируется на все 54 видео в порядке: коридор линии падения →
остальное 13.08 → 12.08 → 11.08. Отсмотр монтажей — минимум топ-3 листа
на видео (сортировка треков по score глобальная).
