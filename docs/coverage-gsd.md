# Реальное покрытие дальних облётов 11–12.08: порог 8 px в сантиметрах

Обновлено: 2026-08-14. Код: `analysis/coverage_gsd.py`, по-сэмпловые таблицы —
`analysis/coverage/<видео>.coverage.tsv`, сводка — `analysis/coverage/summary.tsv`.

Стенд врезок (`docs/video-analysis.md`, «Порог различимости») дал правило:
цветной предмет доходит до отсмотра от 8 px кадра. Здесь порог переведён
в сантиметры для каждого момента каждого ролика 11–12.08: фокусное —
самокалибровкой по панорамированию (`docs/focal-length-calibration.md`,
реализация — `analysis/geoproject.py`, семантика углов провалидирована
попаданием трассировки в триангулированный рюкзак), дальность до склона —
трассировкой центрального луча в Copernicus GLO-30.

## Как читать

«Покрытие рюкзака 80%» = 80% сэмплов ролика (шаг 2 с) имели масштаб, при котором
предмет 1 м занимает ≥ 8 px. Размеры: рюкзак 1.0 м, куртка 0.6 м, крышка 0.17 м.
Проценты — по времени ролика, не по площади склона. Оговорки метода — в конце.

## Слепое пятно склона между зоной интереса и вещами (14.08)

Склон, куда сорвавшийся из зоны интереса попадает, если успел тормозить
(зарубился, зацепился) — то есть остановился выше вещей. Полигон
~520×550 м, высоты 4640–5310 м (`analysis/coverage/sklon-poligon-2026-08-14.json`,
слой «Слепое пятно склона» на карте).

Расчёт: `analysis/coverage_polygon.py` — тот же метод центров кадра, что у
внешней группы; все 38 роликов 11–13.08 с телеметрией подвеса, сетка 30 м,
ячейки — `analysis/coverage/sklon-poligon-2026-08-14.cells.tsv`:

- **69% площади ни разу не попало в центр кадра ни одного пролёта**
  (допуск 75 м); с допуском 150 м — 23%.
- С измеренным масштабом (предмет 1 м ≥ 8 px) осмотрено 20% площади.
- По высотам: полосы **4700–4900 м** (слепые 86–96%) и **5100–5300 м**
  (62–87%) практически не осмотрены; полоса 4900–5100 м осмотрена наполовину.
- Попадания роликов 13.08 идут без масштаба (фокусное для них не мерялось) —
  учтены как «смотрели, масштаб неизвестен» (11% ячеек): долю «осмотрено
  с масштабом» это занижает, долю слепых не меняет.

## Оговорки

- GSD считается по центру кадра (как в расчёте покрытия внешней группы);
  по краям кадра масштаб хуже — оценка покрытия оптимистична для краёв.
- «Мимо рельефа» = центральный луч не встретил склон в пределах 6 км / тайла
  DEM: панорамы по гребням и небу. Склон в такие моменты не осматривается,
  но и масштаб не определён.
- Фокусное измеримо только на панорамах; зависаниям присваивается медиана
  оценок в окне ±20 с (минимум 3 оценки). Участки без оценок считаются
  непокрытыми — безопасная сторона.
- Пороги — для цветных предметов; белое/серое/припорошенное детектор не ищет
  ни при каком масштабе (слепая зона по цвету, см. стенд врезок).
- Модель высот на этой стене врёт до 58 м (`docs/nezavisimyy-analiz/06-…`), и
  завышенный DEM занижает дистанции → приукрашивает покрытие. Аудит 14.08
  (пересчёт всех роликов со сдвигом DEM −30/−58 м,
  `analysis/review/geoprojection.md`, раздел «Методологический аудит»):
  вердикты «неосмотрено» устойчивы — все шесть роликов остаются неосмотренными;
  «осмотрено уверенно» (крупные планы стены 12.08) тоже держится (96–100% при
  любом сдвиге). Плывут два дневных ролика 11.08 — `153833` и `160637`:
  при DEM −58 их покрытие «по-крупному» падает с 71–81% до 36–42%. **Считать
  их покрытие завышенным**; на списки «неосмотренного» это не влияет, но
  полагаться на «осмотрено по-крупному» для этих двух участков нельзя.
